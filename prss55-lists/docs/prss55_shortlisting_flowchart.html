Site-level triage · deterministic · fully auditable

How a predicted PRSS55 cleavage site becomes a ranked candidate

Three scripts turn raw model windows into an annotated, ranked shortlist for wet-lab review. Every exclusion and review flag is a named, inspectable rule — nothing is silently dropped from the output.

Pipeline flow

Each stage is one script, run in sequence from the project root. UniProt and AlphaFold lookups are cached per protein accession, so proteins with many candidate sites are only fetched once.

Triage decision logic

Stage 3, in full: each site passes through two independent rule gates. A hard exclusion always wins; review flags accumulate but never remove a row from the output.

ELIGIBLE — no automatic conflict REVIEW — needs human interpretation EXCLUDE — sequence, processing, membrane, or compartment conflict

Scientific cutoffs & assumptions

What each rule actually checks, where the evidence comes from, and how much confidence to place in it — the distinction that matters most for reading the shortlist.

P1–P1′ bond definition Biological convention Central Arg = P1 (--p1-offset 4, default); Arg↓P1′ Established for this dataset; recorded per site

Processing / TM overlap UniProt, deterministic Overlaps Signal, Propeptide, Initiator-Met, Transmembrane, or Intramembrane Hard exclusion
Compartment accessibility UniProt, deterministic Cytoplasmic topology, or subcellular location is Cytoplasm / Nucleus / Chromosome / Mitochondrion / Peroxisome with no accompanying Secreted / surface / acrosome term Hard exclusion — PRSS55 is surface / extracellular; an accessible term anywhere in the annotation overrides
Secretory-pathway residency UniProt, deterministic Subcellular location is Golgi apparatus / Endoplasmic reticulum / Lysosome with no Secreted / surface term Review only — may be transiting through, not permanently resident
Exposure robustness AlphaFold pLDDT, computational pLDDT ≥ 70 → Medium · < 70 → Low · no data → Unknown No "High" tier without an experimental structure
Local contact density AlphaFold Cα geometry, computational ≥ 20 Cα atoms within 8Å of the 8-mer window Provisional heuristic — not experimentally calibrated
Secondary structure at bond PyDSSP on AlphaFold model Helix (H) or strand (E) at P1 or P1′ Review only — coil / loop favored
Intramolecular salt bridge AlphaFold residue geometry, computational A charged P1 or P1′ residue (Arg/Lys/Asp/Glu) has an oppositely-charged residue within 8Å (Cα–Cα proxy) Provisional heuristic; substrate-side only — does not model PRSS55's own (unsolved) active site

Pfam / InterPro family UniProt, deterministic Recorded (family_annotations) but never gates triage Protein-level evidence, not site-level — deliberately excluded from scoring

Reading the shortlist. This is a cleavability-prioritization workflow, not a claim of confirmed cleavage. prob_cleavage ranks the upstream model's predictions after structural exclusions — it is not a probability that the intact protein is cleaved in vivo. RSA, pLDDT, and secondary structure all come from a single AlphaFold model and do not capture native complexes, glycans, membranes, or conformational ensembles. Every EXCLUDE and REVIEW row is retained with its reason, for human review before selecting wet-lab targets.
